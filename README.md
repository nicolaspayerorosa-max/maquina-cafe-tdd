# Máquina de Café - TDD

Proyecto de una máquina dispensadora de café desarrollada con **T.D.D.** (Test Driven Development) en Java y JUnit 4.

## Estructura
- `src/main/java`: Vaso, Cafetera, Azucarero, MaquinaDeCafe
- `src/test/java`: pruebas unitarias de cada clase
- `.github/workflows/ci-pipeline.yml`: pipeline de CI con GitHub Actions

## Ejecutar las pruebas
```
mvn test
```
